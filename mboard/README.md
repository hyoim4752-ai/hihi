# 엠보드 업무도구

**배포는 파일 공유** — `엠보드 업무도구.html` 파일을 동료에게 보내면, 그 파일이 열릴 때 여기 올라온 새 판을 받아 스스로 새 판으로 바뀝니다.

항상 최신판이 열리는 주소 (GitHub Pages를 켠 뒤):
https://hyoim4752-ai.github.io/hihi/mboard/엠보드%20업무도구.html

## 고칠 때 규칙
- 최신판은 항상 `엠보드 업무도구.html` (번호 없는 이름)에 덮어씀
- `version.json` 의 `ver` 를 새 번호로 올림 → 열려 있던 화면·받아 둔 파일에도 「새 판이 나왔습니다」 안내가 뜸
